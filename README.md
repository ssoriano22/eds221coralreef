# EDS 221 - Coral Reef Model

**Description:** This is the repository containing files related to a project to build a model of a coral reef ecosystem in Mo'orea. This ecosystem has a recent history of disturbance and recovery over the years 2004-2024, with disturbances including Crown of Thorns sea star crises (2008 & 2010), a cyclone crisis (2012), and a marine heatwave/bleaching crisis (2022).

Thir repo currently contains the following:

| File Name | Description |
| --------- | ----------- |
| roll_dice.R | An R script that generates random die rolls for two dice. |
